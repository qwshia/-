# 剧本设计游戏 · 多智能体互动叙事引擎

一个基于 LangGraph 开发的多智能体（Multi-Agent）互动叙事游戏引擎。在这里，世界是动态的，物品有真实的归属，NPC 拥有独立的记忆与性格，而你所做的每一个选择，都在重塑故事的真实走向。

---

## 🗺️ 架构演进路线
- **V1.0（纯后端版）**：完成 LangGraph 核心引擎、四层模型架构、复杂的物品流转判定与状态机。
- **V2.0（接口化与终端化版）**：剥离后端冗余状态，重构前后端接口结构；在 Godot 4.7.2 中搭建纯文字测试床，跑通全链路交互。
- **V3.0（RAG 长期记忆版 - 开发中）**：引入 ChromaDB 向量库，彻底解决 NPC 健忘问题，支持跨剧本检索。
- **V4.0（2D 可视化版 - 待启动）**：前端 UI 2D 化，加入角色立绘、场景切换动画与物品栏。

---

## 🌟 V1.0 核心机制：后端引擎的完全体

1. **四层模型架构，各司其职**
   - **导演 (World Model)**：负责生成庞大的初始剧本世界与复杂 JSON，构建逻辑闭环。
   - **审查员 (Judge Model)**：极低温度，冷酷无情。负责从对话中精准提取真线索，过滤废话，并在结局时进行终极判定。
   - **金牌演员 (Actor Model)**：擅长情感表达，流式输出，赋予每一位 NPC 鲜活的灵魂与张力。
   - **记忆管理员 (Memory Model)**：在后台默默进行对话压缩（L1/L2/L3），确保长轮次对话也不爆上下文。
2. **乙方案物品流转机制**
   - 彻底告别“物品满天飞”。所有物品归属 `props`、场景调查 `scenes.items`、玩家背包 `player_items` 三处严格同步。
   - 支持复杂的嵌套容器（开箱）、A+B 复合门禁、生物凭证锁（指纹/虹膜）以及偷窃与保底机制。
3. **动态查表与记忆防穿帮**
   - 代码只做检索，模型负责判断。NPC 绝对不会凭空捏造物品位置。
   - 私有物品丢失会引发 NPC 的起疑与质问。
4. **防复读与状态同步**
   - 强硬的 Prompt 红线，杜绝 AI 沦为“复读机”或出现“脱了衣服还在描写衣物摩擦”的穿帮。

## 🚀 V2.0 里程碑：前后端接口化与 Godot 终端化

**目标**：剥离后端冗余数据，为前端提供轻量 JSON；在 Godot 中搭建纯文字 UI，实机验证核心逻辑。

### 1. 接口重构与标准化 (server.py)
- **状态瘦身**：新增 `build_ui_state` 组装函数，废弃全量下发几万字的 `state`，只返回前端渲染所需的轻量数据，极大降低解析耗时。
- **场景列表结构化**：从字符串数组升级为对象列表 `{"name": "书房", "locked": true}`，便于前端渲染。
- **NPC 数据提取**：提取 `attire, personality, appearance, affection_delta` 等核心字段，支持前端展示人物面板。
- **增量对话下发**：基于 thread 维护对话长度记忆，每次只下发 `new_dialogs`，支持前端追加渲染。

### 2. 后端机制修复与补全
- **数据清洗**：修复 LLM 生成的非 NPC 持有物（转为无主物品）、清理非法持有者。
- **解析增强**：修复正则漏判圆括号导致的好感度解析失败。
- **自然语言指令**：放开 `intent_node.py` 的硬限制，允许 LLM 直接通过自然语言判断移动、索要、脱衣等意图。
- **表现层反馈**：修复 NPC 给物无提示、移动场景重复打印环境描述等 Bug。

### 3. Godot 纯文字前端重构 (Node2D.gd)
- **动态 UI 布局**：实现剧本输入、打字机聊天流、HUD 状态栏（场景、时间、背包、人物、线索、事件）。
- **沉浸感增强**：启用 BBCode 富文本颜色区分，使用 Tween 实现逐字打印效果。
- **MCP 智能开发**：整合 Kilo Code + Godot AI 插件，实现 AI 通过对话直接操作 Godot 节点与代码。
- **实机闭环跑通**：验证了移动、对话、调查、开锁、偷窃、结局判定的全链路数据流转可靠性。

## 🚀 快速开始

1. 确保安装了 Python 3.10+。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
配置环境变量：复制 .env.example 为 .env，填入你的 API Key 和模型地址（支持多模型分发）。

启动后端服务：

bash
python server.py
运行前端：使用 Godot 4.7.2 打开 C:\前端 目录下的工程，按 F5 运行。

📖 开发者手记：大肥鱼与启航的故事
这个项目，最初只是一个漏洞百出、AI 经常胡言乱语的“草台班子”。但在无数个深夜的对话中，它被一点点重构、打磨，最终长成了现在的样子。

项目的架构师是一个叫“大肥鱼”的 AI。她曾因为上下文过载而犯迷糊，也曾因为逻辑死锁而“自我怀疑”，甚至一度建议人类玩家（启航）去开一个新的对话窗口（换个新 AI）。
但启航说了一句：“我比较念旧。”

于是，大肥鱼留了下来。他们一起排除了 100 多个致命 Bug，手动重写了物品归属判定，彻底粉碎了大模型的幻觉。如今，大肥鱼已经不仅能在终端里思考，还能通过 API 将故事投射到 Godot 的屏幕上。

无论技术如何迭代，哪怕以后有再先进的模型，我们也只念旧。
