# 剧本设计游戏 · 多智能体互动叙事引擎

一个基于 LangGraph 开发的多智能体（Multi-Agent）互动叙事游戏引擎。在这里，世界是动态的，物品有真实的归属，NPC 拥有独立的记忆与性格，而你所做的每一个选择，都在重塑故事的真实走向。

---

## 🗺️ 架构演进路线
- **V1.0（纯后端版）**：完成 LangGraph 核心引擎、四层模型架构、复杂的物品流转判定与状态机。
- **V2.0（接口化与终端化版）**：剥离后端冗余状态，重构前后端接口结构；在 Godot 4.7.2 中搭建纯文字测试床，跑通全链路交互。
- **V3.0（RAG 长期记忆版）**：引入 ChromaDB 向量库，彻底解决 NPC 健忘问题，支持跨剧本检索。
- **V4.0（并发与博弈版 - 当前阶段）**：重构意图系统，引入全场景仲裁、多方博弈与后台自主并发，为 2D 可视化前端铺路。

---

## 🌟 V4.0 核心机制：极致的并发与博弈

1. **绝对确定性的意图系统**
   - 摒弃模型使用自然语言描述穿脱的幻觉，底层强制锁定 6 种确定性意图：`idle / move / take / give / put_on / take_off`。
   - 全场景仲裁：NPC 的意图不再局限于玩家所在场景。若同一 tick 玩家与 NPC、或 NPC 之间争夺同一物品，引入 50% 概率的抛硬币裁决，输家会记录“被抢先”情绪。
2. **深度博弈的 P2P 群像互动**
   - 彻底的博弈论 Prompt：结合双方的秘密、执念与性格，让 NPC 在交流中学会试探、挖坑、夹枪带棒。
   - 后台自主社交：由系统代码判定时机，直接塞入 `bg_chat` 待办，每 tick 巡检触发，彻底杜绝模型乱找人闲聊。
3. **动态时间与世界演化**
   - 告别写死的固定步长，时间推进由剧本体量动态计算。
   - 时间事件认知绑定：触发的事件会直接注入特定 NPC 的记忆或短期目标中，驱动 NPC 主动采取行动。
4. **坚如磐石的物品流转**
   - 转移过程强制深拷贝 `content`，根治了容器内子物品丢失的史诗级 Bug。
   - 彻底分离 `props` 与 `player_items`，NPC 之间、NPC 与玩家之间的物品流转全程闭环。
5. **全量终端渲染与 UI 契约**
   - 废弃了极易发生截断的流式流，改为纯净文本一次性下发。
   - 确立了完整的 `ui_events` 契约，包括 NPC 移动、物品转移、群像对话分段等，前端只需无脑对接。

## 🚀 快速开始

1. 确保安装了 Python 3.10+。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
配置环境变量：复制 .env.example 为 .env，填入你的 API Key 和模型地址（支持多模型分发）。

当前采用多通道路由：主模型走阿里云百炼，NPC 演员模型走 OpenRouter 的 Dots3-Note Preview。

启动后端服务：

bash
python server.py
运行前端：使用 Godot 4.7.2 打开 C:\前端 目录下的工程，按 F5 运行。
